# Инструкция по использованию parse_csv.py

## Назначение
Скрипт парсит CSV файл и конвертирует его в JSON формат с полями: `name`, `level`, `desc`, `icon`.

## Требования
- Python 3
- Файл `craft.json` для поиска иконок (если иконка не указана в CSV)

## Формат CSV файла
CSV файл должен иметь следующую структуру:
- Первая строка: заголовки (пропускается)
- Вторая строка: подзаголовок "Иконка" (пропускается)
- Далее данные с колонками:
  1. Наименование предмета
  2. Уровень
  3. Класс (игнорируется)
  4. Характеристики/Описание
  5. Иконки

## Использование

### Базовое использование
По умолчанию скрипт использует файлы:
- Входной CSV: `craft1_6.csv`
- Справочник иконок: `craft.json`
- Выходной JSON: `craft1_6.json`

```bash
python3 parse_csv.py
```

### Изменение имен файлов
Отредактируйте переменные в конце файла `parse_csv.py`:

```python
if __name__ == '__main__':
    csv_file = 'ваш_файл.csv'           # Входной CSV файл
    craft_json_file = 'craft.json'      # Файл для поиска иконок
    output_file = 'результат.json'      # Выходной JSON файл
    
    parse_csv_to_json(csv_file, craft_json_file, output_file)
```

## Логика работы

1. Скрипт читает CSV файл и пропускает первые 2 строки (заголовки)
2. Для каждой записи извлекаются поля:
   - `name` - из первой колонки
   - `level` - из второй колонки
   - `desc` - из четвертой колонки (многострочные описания объединяются)
   - `icon` - из пятой колонки
3. Если иконка не указана в CSV, скрипт ищет её по имени в `craft.json`
4. Результат сохраняется в JSON файл

## Пример результата

```json
[
  {
    "name": "Деревянная удочка",
    "level": "1",
    "desc": "(Актив): Шанс выудить рыбку - 40%\n|cffff0000Доступен с 1 уровня|r",
    "icon": "BTNTrade_Fishing.png"
  }
]
```

## Примечания
- Многострочные описания автоматически объединяются символом новой строки `\n`
- Если иконка не найдена ни в CSV, ни в craft.json, поле `icon` будет пустой строкой
- Пустые строки в CSV автоматически пропускаются
